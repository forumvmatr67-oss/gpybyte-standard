# ipybyte – specification

## Name
**ipybyte**  
Symbol: **IpyB** or **Ipy**

## Definition
1 ipybyte = 1024 hpybytes = 2¹¹⁰ bytes  
Exactly: 1 297 992 692 803 371 370 296 032 963 379 712 bytes

## Relationship to other units
| Unit | Value in ipybyte |
|------|------------------|
| 1 hpybyte | 1/1024 ipybyte |
| 1 gpybyte | 1/1 048 576 ipybyte |
| 1 yobibyte | 1/1 073 741 824 ipybyte |

## Conversion examples
- **Bytes**: 2¹¹⁰ B
- **Mebibytes (MiB)**: 2⁹⁰ MiB = 1 237 940 039 285 380 274 899 124 224 MiB
- **Gigabytes (GB)**: ≈ 1.29799 × 10²⁷ GB

## Proposed use
Quantifying universal data (e.g., information content of a galaxy).

## Status
Unofficial – part of the gpybyte/hpybyte/ipybyte proposal series.
