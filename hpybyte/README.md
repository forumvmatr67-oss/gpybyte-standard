# hpybyte – specification

## Name
**hpybyte**  
Symbol: **HpyB** or **Hpy**

## Definition
1 hpybyte = 1024 gpybytes = 2¹⁰⁰ bytes  
Exactly: 1 267 650 600 228 229 401 496 703 205 376 bytes

## Relationship to other units
| Unit | Value in hpybyte |
|------|------------------|
| 1 gpybyte | 1/1024 hpybyte |
| 1 yobibyte | 1/1 048 576 hpybyte |
| 1 ipybyte | 1024 hpybyte |

## Conversion examples
- **Bytes**: 2¹⁰⁰ B
- **Mebibytes (MiB)**: 2⁸⁰ MiB = 1 208 925 819 614 629 174 706 176 MiB
- **Gigabytes (GB)**: ≈ 1.26765 × 10²⁴ GB

## Proposed use
Century-scale data archiving, interstellar data transfer budgets.

## Status
Unofficial – part of the gpybyte/hpybyte/ipybyte proposal series.
