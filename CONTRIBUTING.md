# How to contribute to gpybyte/hpybyte/ipybyte

Thank you for your interest! We follow the standard GitHub flow.

## Ways to contribute
- **Open an issue** – for questions, discussions, or to report a mistake.
- **Submit a pull request** – for direct changes to the specification texts.

## Before making a PR
1. Check if an issue already exists for your topic.
2. If not, open a new issue to discuss your proposal.
3. Once the idea is approved, fork the repository, create a branch, and make your changes.
4. Write clear commit messages and reference the issue number.

## Style guidelines
- Use plain English, present tense, and concise definitions.
- All binary units must be clearly defined as powers of 1024.
- When adding comparisons to SI/IEC units, include both byte‑exact and approximate values.

## Review process
- Every PR will be reviewed by at least one maintainer.
- Changes may be requested. Once resolved, the PR will be merged.
