# GIS – Gpybyte Independent Standard (кратко для пользователей)

**Что это?**  
GIS — это открытый стандарт для измерения очень больших объёмов данных. Он вводит новые единицы: `ipybyte`, `hpybyte`, `gpybyte`, `jpybyte` и далее по алфавиту.

**Зачем?**  
Йобибайт (2⁸⁰ байт) может стать слишком маленьким для данных будущего. Мы предлагаем простые названия и правила.

**Как устроено?**  
- `1 ipybyte = 2⁹⁰ байт` (двоичная основа)  
- Каждая следующая единица умножается на **1000** (десятичный шаг):  
  `hpybyte = 1000 × ipybyte`  
  `gpybyte = 1000 × hpybyte`  
  `jpybyte = 1000 × gpybyte`  
  и так далее: `kpybyte`, `lpybyte`…

**Точные значения:**  
ipybyte ≈ 1,24×10²⁷ байт
jpybyte ≈ 1,24×10³⁶ байт
