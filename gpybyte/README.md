# gpybyte – specification

## Name
**gpybyte**  
Symbol: **GpyB** (binary) or **Gpy** (informal)

## Definition
1 gpybyte = 1024 yobibytes = 2⁹⁰ bytes  
Exactly: 1 237 940 039 285 380 274 899 124 224 bytes

## Relationship to other units
| Unit | Value in gpybyte |
|------|------------------|
| 1 yobibyte (YiB) | 1/1024 gpybyte |
| 1 zebibyte (ZiB) | 1/1 048 576 gpybyte |
| 1 hpybyte | 1024 gpybyte |
| 1 ipybyte | 1 048 576 gpybyte |

## Conversion examples
- **Bytes**: 2⁹⁰ B
- **Mebibytes (MiB)**: 2⁷⁰ MiB = 1 180 591 620 717 411 303 424 MiB
- **Gigabytes (GB)**: ≈ 1.23794 × 10²¹ GB

## Proposed use
Global data storage, exascale computing, future internet traffic aggregates.

## Status
Unofficial – part of the gpybyte/hpybyte/ipybyte proposal series.
